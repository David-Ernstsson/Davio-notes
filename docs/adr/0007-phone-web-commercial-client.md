# Phone-first web is the commercial client

Owner-locked 2026-09-21. The commercial learner client is one phone-first web app. A desk, if it happens, is that same phone layout stretched. German still launches through Google Play. Packaging this web client for Play is a later decision. It is not a second, native design of Explore, play, and close.

[ADR-0001](0001-responsive-web-v1.md) and [ADR-0003](0003-mobile-first-phone.md) already chose a phone web app for the Gym. The later mandate and V1 foundation lock the first commercial release as German on Android through Google Play, and they do not name a native runtime. This decision keeps both. The learning journeys designed for this client stay the spec when Play packaging happens. Store moments (purchase, review, install) are that later packaging, not a new sitting.

**Considered Options:** an installed native Android app as the commercial client, with the phone-web prototypes only as a bench. Rejected. The learning flows would be built twice, and the only named client technology was already the phone web app.
