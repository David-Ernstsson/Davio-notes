# Mobile-first phone sitting

The Gym is used on a phone, not at a desk. v1 UI follows prototype variant C (stepped sitting: Read → Notice → Gap map), not a magazine or puzzle-first desktop layout. Still one responsive **web** app (ADR-0001), not Expo: a phone browser is enough. Desk, if it happens, is the same phone layout stretched, not a second design.

The commercial client is a native Expo app ([ADR-0011](0011-native-expo-commercial-client.md)); "not Expo" here is the Gym. The phone-first layout rule still holds.
