# Responsive web client in v1, not a native app

The Gym must work in a **phone browser**. Expo/React Native was a preference, not a requirement. v1 is **one responsive web app**. A native phone app is later, after the Core loop is proven. Desk use is not a separate layout (see ADR-0003).

The web app stays the Gym and prototype bench. The commercial client is native from the start: [ADR-0011](0011-native-expo-commercial-client.md), 2026-11-16.
