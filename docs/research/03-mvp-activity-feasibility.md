# MVP Activity types a solo hobby can ship

Synthesis of tickets 01, 02, and 08. Not a new literature review.

## Recommendation (few and deep)

One sitting = three moves on **the same** owner-authored piece:

1. **Read / listen** a 200–400 word B1–B2 adult text (desk can show a longer cut; phone the short cut). TTS or owner-read audio.
2. **Noticing** — one “why *dem* / this word order?” puzzle in that text (Focus on Form, not a worksheet).
3. **Gap mark** — tiny probe or “I don’t control this yet,” feeding a Grammar-only Gap map.

Optional fourth, same sitting or next day: **easy re-read / re-listen** of yesterday’s piece (fluency on known language). That is the “repetitive” half research says you still need.

That is enough for a two-week interestingness test. Do not add a carnival of types.

## Options compared

| Type | Ship for v1? | Why |
| --- | --- | --- |
| Curated reading of owned text | **Yes — core** | Meaning-focused input; only legal stored corpus (08) |
| Listening of the same text | **Yes — core** | Owner asked for listening; TTS is extra licence, not extra pedagogy |
| Noticing / explain-this-sentence | **Yes — core** | Closest to Schmidt/Long/Ellis; owner’s job vs Immersion (01, 02) |
| Gap map probes + self-marks | **Yes — core** | Personalization that is not a skill tree (01) |
| Easy re-read / re-listen | **Yes — small** | Nation fluency strand; Suzuki task repetition (02) |
| Spaced return to a noticed form in a *new* text | **Yes — later in the two weeks** | Retrieval, not Anki-as-product (01) |
| Vocab SRS as the loop | **No** | Wrong core; Gap map is Grammar-only (01, 07) |
| Grammar drills / clozes as the sitting | **No** | Rejected by owner and by Ellis/Lightbown (01) |
| AI conversation / speaking tiles | **No for v1** | Apps fail here; Immersion can supply output; owner left speaking out (02, 07) |
| Shadowing | **No for v1** | Extra recording UX; not required for the Gym job |
| Translation exercises | **No** | Constrained response; streak-app shape (02) |
| Capture emails/podcasts/news ingest | **No** | Ruled out; DW/ARD/DLR cannot be stored (06, 08) |
| New mini-game each day | **No** | Variety of *skins* is the streak-app failure (02) |

## Content burden

Ten to twenty pieces for two weeks. That is a writing/review task, not a crawler. Agents can draft; the owner must rewrite so the text is theirs (08, German copyright).
